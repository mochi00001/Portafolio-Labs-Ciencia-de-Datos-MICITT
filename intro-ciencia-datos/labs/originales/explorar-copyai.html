Completo Práctica de Laboratorio - Explorar CopyAI

Objetivos

Esta práctica de laboratorio ofrece oportunidades para que los alumnos exploren herramientas para el desarrollo creativo de material de mercadeo mediante el modelo de lenguaje IA proporcionado por el sitio web CopyAI.

Parte 1: Explorar el sitio web de CopyAI y sus herramientas

Parte 2: Explorar las Opciones de Acceso y la Información sobre Precios

Parte 3: Registro y Creación de un Producto de Mercadeo

Antecedentes / Escenario

En esta práctica de laboratorio, visitará y explorará las características y los productos que ofrece el sitio web https://www.copy.ai/. También se registrará con una cuenta gratuita para crear un producto de mercadeo.

=  Un dispositivo con un navegador de Internet y una conexión a Internet

Parte 3: Regístrese y cree un producto de mercadeo

Paso 1: Regístrese para una cuenta gratis

a.  Regístrese para obtener una cuenta gratuita con el método que elija.

b.  CopyAI le proporcionará información para el registro. Utilice la información proporcionada para iniciar sesión en la cuenta.

c.  Proporcione la información necesaria a CopyAI para registrar una nueva cuenta.

Paso 2: Cree un producto de mercadeo

Después de inscribirse, puede crear un nuevo proyecto.

a.  Haga clic en Crear nuevo proyecto.

b.  Proporcione un Título de Proyecto u omita este paso.

c.  Si lo desea, elija una herramienta diferente para crear su primer producto. Por ejemplo, en el panel izquierdo debajo del encabezado Herramientas, haga clic en Herramientas de escritura > Estilo libre.

d.  En el campo Describa su producto, proporcione una breve descripción de su producto.

e.  Elija un tono si lo desea. Haga clic en Crear Copia para la descripción generada por IA.
