SQL en el mundo

Primer contacto con un editor SQL real. El objetivo del laboratorio es entender la estructura básica de una consulta —SELECT, FROM, WHERE— usando tres tablas de juguete: saludos en varios idiomas, formas geométricas y países del mundo.

Módulo 6 Bases de datos relacionales y SQL Julio 2026
Qué practiqué

De la hoja de cálculo a la consulta

En Excel se navega y se filtra a mano. En SQL se describe el resultado que se quiere y el motor lo produce. Este laboratorio introduce las tres piezas mínimas: qué columnas (SELECT), de qué tabla (FROM) y con qué condición (WHERE).

  • El comodín * significa «todas las columnas».
  • Los operadores son los matemáticos normales: <, >, =.
  • = también compara texto: color = 'red' (comillas simples, y respetando mayúsculas del dato).
  • Los números van sin separadores: diez millones se escribe 10000000.
  • AND y OR combinan condiciones.
Consultas

Recorrido del laboratorio

Seleccionar todo

SELECT * FROM hello;
SELECT * FROM shapes;

La vista de imagen de la plataforma dibuja las formas seleccionadas — una forma visual de comprobar qué devolvió la consulta.

Filtrar con WHERE

-- formas con exactamente 5 puntos
SELECT * FROM shapes WHERE dots = 5;

-- formas con menos de 3 puntos
SELECT * FROM shapes WHERE dots < 3;

-- formas rojas / estrellas
SELECT * FROM shapes WHERE color = 'red';
SELECT * FROM shapes WHERE shape = 'star';

La tabla de países

-- países de Asia
SELECT * FROM countries WHERE continent = 'Asia';

-- países con población menor a 10 millones
SELECT * FROM countries WHERE population < 10000000;

Condiciones combinadas

-- círculo Y con 4 puntos
SELECT * FROM shapes WHERE shape = 'circle' AND dots = 4;

-- desafío: formas del lado derecho con menos de 5 puntos
SELECT * FROM shapes WHERE xloc > 0 AND dots < 5;

Lo que me llevo

Nota

¿Por qué empezar SQL con datos «de juguete» (formas, saludos)?

Porque separa el aprendizaje de la sintaxis del ruido de un dataset real. Con la vista de imagen de la plataforma, cada WHERE tiene un resultado visual inmediato: se ve qué se seleccionó y qué no. La misma lógica (SELECT … FROM … WHERE …) escala luego a las tablas de países y de películas del resto del curso.
