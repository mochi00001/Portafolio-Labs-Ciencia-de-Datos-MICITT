## 1. Introducción al módulo (3.0.1)

Este módulo cubre el paso de **preparación de datos** dentro del ciclo de vida del análisis. El objetivo es asegurar que los datos sean:

- **Relevantes** para el propósito del análisis.
- **Correctos en formato** para las herramientas a usar.
- **Libres de datos no válidos o corruptos**.

---

## 2. Selección de Datos Relevantes (3.1.2)

Seleccionar datos relevantes implica determinar qué tipo de datos se necesita y dónde encontrarlos. El criterio rector es que los datos elegidos respondan directamente a la pregunta de negocio original — usar solo lo que aporta señal, no todo lo disponible.

**Ejemplo del módulo:** un productor de cine evaluando la viabilidad de adaptar un libro a película necesitaría datos sobre ventas del libro (por autor, género y demografía), rentabilidad de películas con tramas/personajes similares y sus fechas de lanzamiento, y datos de actores/locaciones de películas exitosas recientes para decisiones de reparto y producción.

A veces los datos necesarios no existen todavía, lo que obliga a crear nuevos procedimientos de recolección. Otras veces se requiere combinar datos de varias fuentes en un formato analizable — este es justamente el tipo de tarea que cubre el laboratorio de este módulo (unir los archivos `Bike_Sales_2021.xlsx` y `Bike_Sales_2022.xlsx`).

### Preguntas clave al seleccionar una fuente de datos

| # | Pregunta |
|---|---|
| 1 | ¿Qué puntos de datos son necesarios para informar el análisis? |
| 2 | ¿Ya tengo acceso a estos datos o debo encontrar un conjunto de otra fuente? |
| 3 | ¿Dónde están las fuentes confiables y verificables de estos datos? |
| 4 | ¿Con qué frecuencia se recopilan y actualizan los datos relevantes? |
| 5 | ¿Cómo se licencian los datos para su uso? ¿Hay algún costo? |
| 6 | ¿Los datos están en un formato que puedo usar (o convertir para usar) con mis herramientas? |

---

## 3. Elemento de práctica (3.1.3)

**Pregunta:** Verdadero o falso — en el análisis de datos, incluso si los datos se recopilan correctamente, su calidad depende de las preguntas que formule el analista.

**Respuesta correcta:** Verdadero.

**Justificación:** Las preguntas de negocio deben definirse con claridad considerando la industria y la competencia. Una mala identificación de la pregunta lleva a interpretaciones erróneas que afectan la eficiencia del negocio y sus resultados, sin importar qué tan bien se hayan recopilado los datos.
